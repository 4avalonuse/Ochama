# OChart Legacy — Auditoria

Status: iniciada após a criação do Ochama.

## Método

Cada arquivo será analisado por:

- responsabilidade
- consumidores
- dependências
- estado próprio
- eventos recebidos/disparados
- duplicações
- acoplamento
- tamanho/coesão
- comportamento percebido pelo usuário
- migrar / reescrever / descartar / preservar como referência

## Regra

O repositório `4avalonuse/ochart` é a referência congelada. A auditoria não altera o legado.
